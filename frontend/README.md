# TODO Frontend

This is the frontend for the TODO application built with React.

## Setup Instructions

1. Install dependencies:
   ```
   npm install
   ```

2. Start the development server:
   ```
   npm start
   ```

The app will run on http://localhost:3000

## Features

- View all TODO items
- Add new TODO items
- Edit existing TODO items
- Mark TODO items as done/undone
- Delete TODO items
- Responsive design
